Yomi CLI is a derivative work of [ani-cli](https://github.com/pystardust/ani-cli), originally published by the ani-cli contributors under the GNU GPL-3.0 license.

The derivative work retains that license and acknowledges the original project for the shell-based terminal interface, interactive episode workflow, player dispatch structure, history handling, and related implementation patterns that formed the starting point for Yomi CLI.

Yomi CLI now uses a separate identity, Yomi.to metadata, MegaPlay playback resolution, a Yomi-specific relay helper, subtitle selection and persistence, and Yomi-specific documentation. The original project is not included as a second executable or source tree in this repository.
